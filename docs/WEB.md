# 本地 Web 入口

Web 界面与桌面应用共用静态页面及 Rust 后端，供本机开发或命令行启动使用。

```bash
cargo run --bin slip-web
```

打开终端输出的完整链接。默认地址为 `127.0.0.1:8025`，每次启动生成新的访问令牌；不要公开分享完整链接。页面默认没有账号，需手动输入邮箱和授权码。

| 配置 | 用途 |
| --- | --- |
| `SLIP_WEB_PORT` | 更改回环端口；`0` 自动选择可用端口 |
| `SLIP_HOME` | 更改本地身份、聊天记录与附件目录 |

桌面应用自动管理端口和进程，无需设置这些变量。Web 不自动加载环境变量中的邮箱账号。不要将它通过反向代理暴露到公网。

上传只接收文件字节与文件名，不接受任意主机路径。下载验证账号、联系人、消息和附件索引，使用短期单次票据；API 校验 Host 和 Bearer 令牌。页面不加载第三方脚本或 CDN。

Web 和桌面都要求正文与附件加密，接收保存后清理对应服务器副本。使用步骤见 [桌面使用指南](DESKTOP.md)。
