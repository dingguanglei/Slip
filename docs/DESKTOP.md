# 桌面使用指南

## 安装

| 系统 | 安装方式 |
| --- | --- |
| macOS 13+，Apple Silicon | 解压 ZIP，将 `Slip.app` 拖入“应用程序”，然后打开 |
| Windows 10 / 11，x86-64 | 完整解压 ZIP，运行 `Slip.exe`；保留同目录运行库和 resources |
| Ubuntu 22.04+，ARM64 或 AMD64 | 下载匹配架构的 DEB，运行 `sudo apt install ./Slip-0.2.0-ubuntu-arm64.deb` 或对应 AMD64 包 |

Ubuntu 安装后可在应用菜单搜索 Slip。DEB 配置 Electron 所需的沙箱文件权限，不需要关闭浏览器沙箱。

当前应用未发行签名或公证。请从本仓库 Release 下载并核对 `SHA256SUMS`，系统可能要求手动授权打开。目标平台的实际验证范围以发行页为准。

## 登录邮箱

Slip 不建立独立账号，也不记住自动登录凭证。打开应用后输入邮箱地址及应用密码/授权码；不要填写邮箱的普通登录密码。

- QQ：在邮箱设置中开启 IMAP/SMTP，生成授权码。
- Gmail：使用支持 IMAP/SMTP 的账号及应用密码；能否创建应用密码取决于账号设置。
- iCloud：使用 Apple 账号生成的 App 专用密码。
- 其他支持的预设邮箱由地址自动识别。自定义服务器目前通过 CLI/TUI 配置。

登录失败时，检查授权码、邮箱协议设置和网络连接。应用不会在失败时尝试明文连接。

## 联系人与消息

左侧头像进入个人信息，气泡图标返回聊天。联系人列表支持按邮箱或备注搜索；加号发送好友公钥交换申请。对方也需要运行 Slip，并完成公钥交换。

点击聊天右上角的详情图标，通过其他可信渠道核对双方公钥指纹。锁图标表示已具备可用的加密密钥；它不能代替人工身份核对。密钥变化时会暂停发送，核对后才能信任新密钥。

输入文字后按 Enter 发送，Shift + Enter 换行。回形针添加图片或文件，最多 8 个附件、合计 12 MB。图片可直接预览，点击附件使用系统保存对话框。发送失败时可重试，未建立加密连接时保留当前草稿。

发送状态表示邮件服务器是否接受了密文，不提供对方已读回执。

## 本地保存和服务器清理

有效消息先解密、验证并可靠保存本地，然后按精确邮件 UID 清理接收副本。发送后也会检查本机已记录密文摘要的发件副本。网络或服务商删除失败时保留重试；损坏邮件、未知协议、密钥变化和普通邮件不会被当作已成功接收的聊天删除。

服务商仍可保留内部备份，Slip 无法验证或删除这些备份。

默认数据目录：

| 系统 | 目录 |
| --- | --- |
| macOS / Linux | `~/.slip` |
| Windows | `%USERPROFILE%\.slip` |

账号目录彼此隔离，包含身份密钥、本地数据库和附件。复制应用不会复制聊天记录。退出账号保留这些数据，关闭应用会清除本次登录会话。备份时请完整备份数据目录，并保护备份本身。

当前不支持多设备身份自动同步。首次在另一台设备登录可能生成不同密钥；不要在未核对的情况下反复信任变化的指纹。

## 安全说明

授权码仅在本次桌面通信进程内存中使用。页面启用沙箱、上下文隔离和网络限制；本地服务使用随机回环端口和访问令牌，关闭应用后随之退出。

本地历史和附件为明文。TOFU、公钥泄露、无前向保密以及元数据边界见 [SECURITY.md](../SECURITY.md)。
